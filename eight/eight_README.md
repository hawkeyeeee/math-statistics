# Лаба 8. Регрессионный анализ: линейная, полиномиальная и логистическая регрессия

## Часть 1 — линейная и полиномиальная регрессия (age → bmi)
**Датасет:** insurance.csv.

- Данные очищены, визуализированы (scatter, гистограммы, boxplot); нормальность обеих переменных проверена критерием Шапиро-Уилка (обе не нормальны, p<0.001)
- Рассчитан коэффициент корреляции Пирсона (r=0.376, слабая положительная связь); доверительный интервал для коэффициента корреляции построен бутстрапом (95% ДИ: 0.35–0.40) — не содержит 0, связь статистически значима
- Построены линейная и полиномиальная (степень 2) регрессии через `statsmodels` и `sklearn`, модели сопоставлены по качеству: **линейная R²=0.111**, **полиномиальная R²=0.240** (RMSE=6.84) — полиномиальная модель точнее описывает зависимость

## Часть 2 — логистическая регрессия (age → hypertension)
**Датасет:** [Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset), n=5 110.

- Данные разделены на обучающую и тестовую выборки
- Построена модель p(age) = 1 / (1 + exp(-(-5.015 + 0.053·age))) — вероятность гипертензии растёт с возрастом
- Построена матрица ошибок, accuracy на тесте — 90.2%
- Отдельно отмечено ограничение модели: при дисбалансе классов (гипертензия у меньшинства пациентов) модель на пороге 0.5 не предсказала ни одного истинно положительного случая (precision/recall=0 для класса «гипертензия») — вывод сформулирован как ограничение точности модели, а не как её успех, несмотря на высокий accuracy

**Инструменты:** pandas, matplotlib, scipy.stats, statsmodels, scikit-learn (LinearRegression, PolynomialFeatures, LogisticRegression, confusion_matrix)
