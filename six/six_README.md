# Лаба 6. Бутстрап-методы построения доверительных интервалов

На выборке (n=20) из экспоненциального распределения (M=5) построены 90%-е доверительные интервалы для математического ожидания, дисперсии и медианы тремя способами:

- **процентильный бутстрап**
- **t-бутстрап** (double bootstrap — с оценкой стандартной ошибки через вложенный ресемплинг)
- **параметрический интервал** — для сравнения с классическим подходом

Для мат. ожидания интервалы получились сопоставимы по ширине (параметрический — 3.81, бутстрап-процентильный — 3.56, t-бутстрап — 4.14), для медианы (для которой параметрической формулы нет) — только бутстрап-методы.

Отдельно исследовано влияние числа бутстрап-реплик B (10 / 100 / 1000 / 5000 / 10000) на устойчивость интервала: ширина и границы интервала стабилизируются уже при B≈1000–5000, дальнейшее увеличение почти не меняет результат. Форма бутстрап-распределения оценки медианы проверена на нормальность критерием Колмогорова-Смирнова.

**Инструменты:** numpy, scipy.stats, pandas, matplotlib
