# Лаба 5. Проверка статистических гипотез

## Часть 1 — параметрические гипотезы
**Датасет:** [Mall Customers](https://www.kaggle.com/datasets/shwetabh123/mall-customers) (данные опроса покупателей торгового центра).

- **z-тест:** гипотеза «мужчины и женщины в среднем тратят 50% дохода» — H0 не отвергнута (p=0.913)
- **t-тест:** гипотеза «доход мужчин выше дохода женщин» — H0 не отвергнута (p=0.214), различие статистически незначимо
- **F-тест:** гипотеза о равенстве дисперсий возраста мужчин и женщин — H0 отвергнута (p=0.042): разброс по возрасту значимо различается между полами
- Все три расчёта продублированы через `statsmodels` (`ztest`, `ttest_ind`) — значения p-value совпали с ручными вычислениями, что подтвердило корректность реализации

## Часть 2 — непараметрические гипотезы
Смоделирован срок службы турбореактивного двигателя как сумма сроков службы отдельных лопаток (n=1000) — по ЦПТ ожидалось нормальное распределение суммы. Критерием Колмогорова-Смирнова проверено согласие эмпирического распределения с нормальным (p=0.634) и гамма-распределением (p=0.845) — обе гипотезы не отвергнуты, эмпирические параметры близки к теоретическим.

**Инструменты:** scipy.stats, statsmodels, numpy, pandas, matplotlib
