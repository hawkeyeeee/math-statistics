# Лаба 1. Разведочный анализ данных (EDA) на pandas

**Датасет:** почасовые данные аренды велосипедов (сезон, погода, температура, влажность, скорость ветра, рабочий/праздничный день).

## Что сделано
- Создан агрегированный признак `Total_count` (сумма аренд по двум точкам выдачи), исходные колонки удалены
- `Date` приведена к `datetime`, из неё извлечён день недели
- Категориальный признак `Functioning Day` перекодирован в `bool`, `Holiday` — в `0/1` через `lambda`
- Введена производная категория `Temperature category` (Freezing / Chilly / Nice / Hot) по порогам температуры
- Построен композитный бинарный признак `Good weather` — учитывает одновременно температуру, влажность и скорость ветра
- Данные сгруппированы по `Seasons × Temperature category` с агрегацией количества аренд

## Результат
Максимум аренд приходится на комбинацию **Summer + Hot**, минимум — на **Spring + Freezing**: спрос сильнее всего связан с тёплой погодой, а не с сезоном как таковым.

**Инструменты:** pandas
