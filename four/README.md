# math-statistics

Лабораторные работы по курсу математической статистики и теории вероятностей: от разведочного анализа данных и распределений до проверки гипотез, дисперсионного, корреляционного и регрессионного анализа. Каждая работа — отдельная папка с ноутбуком и своим README.

| № | Тема | Датасет | Ключевые методы |
|---|------|---------|------------------|
| [one](./one) | EDA на pandas | Аренда велосипедов (почасовая) | Работа с датами, категоризация признаков, группировки |
| [two](./two) | Pandas + основы теории вероятностей | MovieLens 1M (1 007 209 оценок) | Джойны таблиц, агрегации, нормальное и экспоненциальное распределения |
| [three](./three) | Теория вероятностей | Симуляция (урна с шарами) | ЦПТ, метод моментов, метод максимального правдоподобия |
| [four](./four) | Интервальные оценки | Среднесуточные температуры по странам | Доверительные интервалы для среднего и дисперсии |
| [five](./five) | Проверка гипотез | Mall Customers (Kaggle) | z-тест, t-тест, F-тест, критерий Колмогорова-Смирнова |
| [six](./six) | Бутстрап-методы | Смоделированная выборка | Percentile bootstrap, t-bootstrap, double bootstrap |
| [seven](./seven) | Корреляционный и дисперсионный анализ | Insurance costs | Пирсон, Спирмен, χ², one-way/two-way ANOVA, тест Тьюки |
| [eight](./eight) | Регрессионный анализ | Insurance costs, Stroke dataset | Линейная/полиномиальная/логистическая регрессия, confusion matrix |

**Стек:** Python, pandas, numpy, scipy.stats, statsmodels, scikit-learn, matplotlib, seaborn
