# Лаба 4. Интервальные оценки

## Часть 1 — теоретические распределения
Для стандартных нормального, Стьюдента и χ²-распределений вручную и через `scipy.stats` рассчитаны квантили, соответствующие заданным вероятностям, с проверкой обратным пересчётом.

## Часть 2 — доверительные интервалы на смоделированной выборке
На выборке из нормального распределения (m=6.0, σ=0.4) построены доверительные интервалы:
- для математического ожидания — отдельно для случаев известной и неизвестной σ
- для дисперсии совокупности
- рассчитан необходимый объём выборки для сужения интервала — потребовалось увеличение выборки в 4 раза (N₁=241 против исходной N)

## Часть 3 — доверительные интервалы на реальных данных
Использован датасет среднесуточных температур по странам. Из всех стран отобраны 10 с максимальным разбросом температур в заданном месяце (Казахстан, Швеция, Молдова и др.). Для каждой страны построены доверительные интервалы для среднего и дисперсии температуры, все интервалы визуализированы на одном графике в порядке убывания дисперсии.

**Инструменты:** scipy.stats, pandas, numpy, matplotlib
